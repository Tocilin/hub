# HUB Design System

Consistency in HUB comes from **shared tokens and primitives**, not identical page templates. Apps may have their own layouts and navigation, but they build them from the pieces below.

- Tokens: [`src/app/globals.css`](../src/app/globals.css)
- Primitives (shadcn/ui + Radix): [`src/components/ui/`](../src/components/ui/)
- Platform components: [`src/components/platform/`](../src/components/platform/)

## Principles

1. **Calm.** Neutral surfaces, restrained color, generous whitespace. Color comes mostly from app identity.
2. **Semantic over literal.** Use `bg-card` and `text-muted-foreground`, never `bg-white` or `text-gray-500`. Raw palette values only appear in `globals.css`.
3. **Accessible by default.** WCAG 2.2 AA: visible focus, ≥ 4.5:1 text contrast, ≥ 24 px targets (prefer 36–44 px for touch), and reduced motion respected.
4. **Add when needed.** No component is built until a screen needs it.

## Tokens

All tokens are CSS variables defined in `:root` (light) and `.dark`, and exposed as Tailwind utilities through `@theme`.

### Color

| Role              | Utility                                            | Use                                                         |
| ----------------- | -------------------------------------------------- | ----------------------------------------------------------- |
| Page background   | `bg-background` / `text-foreground`                | The canvas                                                  |
| Surface           | `bg-card` / `text-card-foreground`                 | Cards, tiles, panels                                        |
| Elevated surface  | `bg-popover` / `text-popover-foreground`           | Menus, dialogs, popovers (add `shadow-overlay`)             |
| Subtle fill       | `bg-muted`                                         | Tracks, wells, placeholder icons                            |
| Secondary text    | `text-muted-foreground`                            | Descriptions, metadata (≥ 4.5:1 on background and muted)    |
| Borders           | `border-border`, `border-input`                    | Dividers / form controls                                    |
| Focus             | `ring-ring`                                        | Focus rings (applied by primitives)                         |
| Interactive       | `bg-primary` / `text-primary-foreground`           | Primary actions                                             |
| Quiet interactive | `bg-secondary`, `bg-accent`                        | Secondary actions, hover fills                              |
| Status            | `text-success`, `text-warning`, `text-destructive` | Status text and icons. Use `bg-*/10` for tinted backgrounds |
| App identity      | `bg-app-{blue,green,amber,rose,violet,teal,slate}` | App tile icons only. White icons on these meet ≥ 3:1        |

### Typography

- Family: **Geist** (`font-sans`) via `next/font`, self-hosted with no layout shift.
- Scale: Tailwind defaults. Common choices:
  - Page title `text-2xl font-semibold tracking-tight`
  - Section title `text-lg font-semibold tracking-tight`
  - Body `text-base`, secondary text `text-sm text-muted-foreground`
- Use `text-balance` on headings and `text-pretty` on paragraphs.

### Spacing & layout

- Spacing: Tailwind's 4 px scale.
- **Page gutter:** `px-gutter`, which is 16 px on phones, 32 px from 768 px and 48 px from 1280 px. Use it for page-level horizontal padding so every screen aligns.
- Content width: `mx-auto max-w-5xl` for platform pages. Apps may choose their own.

### Radius, elevation, motion

| Token               | Utilities                                                           | Notes                                                            |
| ------------------- | ------------------------------------------------------------------- | ---------------------------------------------------------------- |
| Radius (base 12 px) | `rounded-sm` … `rounded-4xl`                                        | Scaled from `--radius`. Tiles use `rounded-2xl` or `rounded-3xl` |
| Elevation           | `shadow-raised`, `shadow-overlay`                                   | Raised = resting surfaces; overlay = floating UI                 |
| Motion              | `duration-fast` (120 ms), `duration-base` (200 ms), `ease-standard` | Animate opacity and transform only                               |

All animation and transition durations collapse under `prefers-reduced-motion: reduce`, so don't build features that depend on motion.

## Themes

Light / Dark / System via `next-themes` (`class` strategy on `<html>`). The choice persists per device in `localStorage` and is applied before first paint.

- Set it with `<ThemeControl />` (Settings).
- Style dark-only overrides with the `dark:` variant, but prefer tokens: a token already switches with the theme.

## Primitives (`src/components/ui`)

Generated by the shadcn CLI (`radix-nova` style) and edited sparingly, so future `shadcn add` updates stay easy.

| Component        | Notes                                                                                                                                            |
| ---------------- | ------------------------------------------------------------------------------------------------------------------------------------------------ |
| `Button`         | Variants: `default`, `secondary`, `outline`, `ghost`, `destructive`, `link`. Use `size="lg"` for primary touch actions. `asChild` wraps a `Link` |
| `Input`, `Label` | Always pair them. Mark validation errors with `aria-invalid`                                                                                     |
| `Card`           | `Card`, `CardHeader`, `CardTitle`, `CardDescription`, `CardContent`, `CardFooter`                                                                |
| `Badge`          | Short status labels, e.g. "Soon"                                                                                                                 |
| `ToggleGroup`    | `type="single"` renders an accessible radio group                                                                                                |
| `Skeleton`       | Loading placeholders that match the final layout                                                                                                 |

**Adding one:** `pnpm exec shadcn add <name>`. Then run `pnpm format` and use it in a real screen in the same change.

## Platform components (`src/components/platform`)

| Component       | Use                                                                              |
| --------------- | -------------------------------------------------------------------------------- |
| `PageHeader`    | Page `h1` with an optional description and trailing `actions` slot               |
| `EmptyState`    | "Nothing here yet." Neutral, and offers the next step via `action`               |
| `ErrorState`    | "Something failed." Announced with `role="alert"`; never shows raw error details |
| `ThemeControl`  | Light / Dark / System segmented control                                          |
| `ThemeProvider` | Mounted once in the root layout                                                  |

Coming in Milestone 3: `AppTile`, `AppGrid`, and the optional `AppShell` (back to HUB, app identity, nav slot, actions).

## States checklist (every screen)

- **Loading:** a `loading.tsx` with `Skeleton`s shaped like the content
- **Empty:** `EmptyState` with a next step
- **Error:** an `error.tsx` using `ErrorState` with a retry
- **Not found / unauthorized:** `notFound()` or a redirect. Never render a half-empty page
- **Validation:** inline field messages with `aria-invalid` and `aria-describedby`
